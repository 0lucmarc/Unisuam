Etapas de um Código de Programação

Explicação da Estrutura de um Código de Programação

Um código de programação é construido com o intuito de resolver problemas através de instruções lógicas e sequenciais. Para isso, precisamos montar 3 etapas fundamentais que todo código deve ter. São eles:

  • Entrada - Etapa onde o programa recebe os dados necessários para realizar o processamento. Esses dados podem ser fornecidos pelo usuário, por arquivos ou por outros sistemas.
  • Processamento - Etapa onde o programa realiza operações e cálculos com os dados de entrada, aplicando algoritmos e lógica para chegar a um resultado.
  • Saída - Etapa onde o programa apresenta os resultados do processamento, seja através de mensagens na tela, arquivos gerados ou comunicação com outros sistemas.

    • Segue abaixo exemplos de cada etapa:

  • Exemplo de Entrada: O usuário digita seu nome e idade.
  • Exemplo de Processamento: O programa calcula quantos anos faltam para o usuário se aposentar.
  • Exemplo de Saída: O programa exibe na tela a mensagem "Faltam X anos para você se aposentar".
    • Exemplo de Estrutura de um Código de Programação

    Segue abaixo um código em python para ser usado de exemplo de estrutura de um código de programação:

    
       # Entrada de dados, solicitando ao usuário o ano atual, sua idade e a idade de aposentadoria
        ano = int(input("Digite o ano atual: "))
        Idade1 = int(input("Digite a idade: "))
        Idade2 = int(input("Digite a idade de aposentadoria: "))

        # Processamento, calculando quantos anos faltam para a pessoa se aposentar
        faltam=Idade2 - Idade1
        print("Faltam", faltam, "anos para a pessoa se aposentar.")
        A = ano
        while A < ano + faltam:
            print(A)
            A += 1
        A = ano + faltam

        # Saída, exibindo o ano em que a pessoa se aposentará
        print("A pessoa se aposentará no ano de", A)
